{%- comment -%} hreflang links for pages that exist in more than one language. A page joins a group with front matter `i18n: ` plus `lang: ` (codes from _data/languages.json). Pages outside a group get none: hreflang must only point at true equivalents. English is x-default. {%- endcomment -%} {%- if page.i18n -%} {%- assign i18n_alts = site.pages | where: "i18n", page.i18n -%} {%- for l in site.data.languages -%} {%- assign alt = i18n_alts | where: "lang", l.code | first -%} {%- if alt %} {%- if l.code == "en" %} {%- endif -%} {%- endif -%} {%- endfor -%} {%- endif -%}
